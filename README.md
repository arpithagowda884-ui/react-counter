React Counter App

📌 Project Description

A simple React Counter Application that allows users to increase, decrease, and reset the counter value using buttons.

🚀 Features

- Increase counter value.
- Decrease counter value.
- Reset counter to zero.
- Simple and interactive user interface.

🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS

⚙️ How to Run

1. Download or clone the project.
2. Open the project in VS Code.
3. Run "npm install".
4. Run "npm run dev".
5. Open the local URL in your browser.

🎯 Purpose

This project helps beginners understand React components, useState Hook, and event handling.
